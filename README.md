# Aafthab Ali Shaik — Portfolio

A responsive React portfolio inspired primarily by itsvg.in's typography, spacious layout, terminal introduction, and project cards. The toolkit and expanded career/project details draw on ritikrana.vercel.app. Original implementation with solid colors only.

## Run locally

Requires Node.js 22.12+ (Node 24 LTS recommended).

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:5173. To verify the production build:

```sh
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this directory to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Select **Vite**, use `npm run build` as the build command and `dist` as the output directory (also specified in `vercel.json`).
4. Deploy. No environment variables, database, or API keys are required.

Vercel runs `npm ci` then `npm run build` (Node 20.19+). The build also regenerates `public/resume.html` from `src/data.js`. `vercel.json` sets long-lived caching for hashed files in `/assets`, 30-day caching for story photos, clean URLs (`/resume`), and security headers.

Alternatively, run `npx vercel` from the project directory and follow the prompts.

## Personalize

Edit `src/data.js` for your name, email, phone, skills, internships, and projects.

- Set `profile.github` and `profile.linkedin` to your full profile URLs.
- Set each project's `live` and `github` values to the real deployment and repository URLs. Empty links are deliberately hidden. GitHub, LinkedIn, RouteWise, and Expression links have been populated from the embedded links in your supplied résumé.
- The supplied project previews are **illustrative interface concepts**, not screenshots of the original apps. Replace the `ProjectPreview` component with your actual screenshots when available.
- The primary résumé is your original PDF at `public/aafthab-ali-shaik-resume.pdf`, linked for download from the hero and About section. Replace this file to update your résumé. A secondary printable HTML version is also generated by `scripts/resume.mjs`.
- Colors, typography, breakpoints, and motion are in `src/style.css`.

## Included interactions

- Project filters, show-more control, and accessible native project dialogs with Escape/backdrop dismissal and focus restoration.
- Interactive terminal: `help`, `whoami`, `skills`, `projects`, `education`, `contact`, and `clear`.
- Light/dark preference saved locally, mobile navigation, expandable experience, current India time, email copying, direct email and telephone links.
- Responsive layouts, reduced-motion support, semantic navigation, keyboard focus states, page metadata, and custom favicon.

Email links open the visitor's mail app. There is no contact-form server, analytics, or visitor data collection. Google Fonts loads the typefaces externally; system fonts remain available as fallbacks.

## Publishing Stories

Edit `src/stories.js`. Each entry has a unique URL-safe `id`, a month (`YYYY-MM`), `category`, `title`, `excerpt`, an array of paragraphs in `body`, and `published`.

```js
{
  id: 'a-new-chapter',
  date: '2026-10',
  category: 'Life updates',
  title: 'A new chapter.',
  excerpt: 'A short introduction to your update.',
  body: ['Your first paragraph.', 'Your next paragraph.'],
  published: true
}
```

Add the entry to the exported array, then build and redeploy (or push to your Vercel-connected repository). Stories show newest first in the scrolling reel, followed by the `milestones` in the order listed. `published: false` hides drafts from the interface, but source files are still bundled; **do not put private content in drafts**.

Readers open a story with **Read the story** and can copy direct links such as `/#story-bnp-innoversite-2026`.

**Story photos:** save them as WebP in `public/stories/` in two sizes: the full photo (max 1600px wide) and an 800px-wide copy named `-800.webp`. For example, with `cwebp`:

```bash
cwebp -q 78 photo.jpg -o public/stories/my-story-1.webp
cwebp -q 72 -resize 800 0 photo.jpg -o public/stories/my-story-1-800.webp
```

Then list them on the story as `images:[{src:'/stories/my-story-1.webp',thumb:'/stories/my-story-1-800.webp',w:1600,h:1200,alt:'What the photo shows'}]`. The first image appears on the card; all of them appear in the story's photo gallery.

## Homepage motion, languages, and sound

`src/Hero.jsx` contains the name spellings and the homepage behavior. English, Telugu, Hindi, and Urdu rotate every 4.8 seconds. Clicking a language selects it and pauses rotation. The play/pause control restarts or stops rotation; pointer hover and keyboard focus on the name pause cycling. Native scripts remain joined for proper shaping. Adjust transliterations in the `names` array if you prefer another spelling.

The homepage uses a staggered name entrance, letter hover colors and symbols, and animated technology text. Reduced-motion settings disable automatic rotation and decorative movement. Sound starts off on every page load and only runs after the visitor explicitly enables it. Audio is an original Web Audio sequence, with short notes on letter hover; no external music stream is used. Sound suspends when the tab is hidden and stops when switched off. Styling is in `src/hero.css`; Stories styles are in `src/stories.css`. All surfaces use solid colors.
